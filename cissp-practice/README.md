# CISSP Practice — English Offline Edition

An English, offline snapshot of [kazuki-hanai's CISSP study app](https://kazuki-hanai.github.io/cissp-practice/), with 1,000 practice questions and nine study chapters.

## Use offline

Download this repository, extract it, and open **index.html** in your browser. No installation, server, or internet connection is required for studying.

- **index.html**: English interface, questions, answer choices, explanations, and textbook.
- **index-ja.html**: unchanged Japanese original, also linked from the English page.
- **README.txt**: detailed offline-use and progress-transfer instructions.

External reference links require an internet connection. This is a snapshot downloaded on November 15, 2026; it does not update automatically.

## Save and transfer progress

Progress is stored in your browser's local storage. Use the same browser/profile and keep the folder at the same location. In **History → Progress data**, use **Export** to save a backup and **Import** to restore it. Import replaces the current progress.

To transfer progress from the original Japanese website, export it from **履歴 → 進捗データ → 書き出す**, then import the JSON file into this app.

## Translation and attribution

Original app and Japanese study material: **kazuki-hanai**, available at the [original website](https://kazuki-hanai.github.io/cissp-practice/).

The English edition uses Google Translate, a local MADLAD model, and AI translation agents, with separate review of interface wording and selected terminology. It is an AI-assisted translation, not an official or fully human-reviewed English edition. The Japanese original is retained for comparison.
