CISSP practice — English offline edition

Open index.html in your normal browser. No installation, server, or internet
connection is needed. Bookmark the local page for quick access while travelling.

Based on:

Includes all 1,000 practice questions, 9 study chapters, and browser icons.
index.html is the English edition: the interface, all 1,000 questions, answer
choices, explanations, and 9 study chapters have been translated to English.
index-ja.html preserves the unchanged Japanese original.

The study content was translated using Google Translate, a local MADLAD model,
and AI translation agents. Interface wording and selected terminology
were reviewed separately. This is not a human-reviewed or official English
edition. The Japanese original is available for comparison.

PROGRESS
Progress is saved in this browser's local storage. Keep the folder at the same
location and use the same browser/profile. Avoid private/incognito mode and
clearing browser data. Keep an exported backup before moving the folder.

Your progress on the online site does not automatically transfer here.
To transfer it, open the online site's History page (履歴), find Progress data
(進捗データ), and choose Export (書き出す). On the English local site's History
page, choose Import and select that JSON file. Import replaces local progress.
The same controls let you back up your offline progress and move it back later.

External reference links still require an internet connection. This is a saved
snapshot; future changes to the online site are not downloaded automatically.

The English page uses the same progress storage key and question IDs as the
previous offline copy. Keep index.html at the same path and use the same browser
to retain existing progress. Previously saved session titles may remain Japanese.
The separate Japanese file may have separate storage depending on your browser.
